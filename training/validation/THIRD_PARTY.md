# Pinned source and dependency notices

This directory contains orchestration and validation source, not vendored model weights, reference recordings, upstream source trees, downloaded corpora or compiled binaries. Building fetches modules identified by `go.mod`/`go.sum`. Python packages belong in the private training environment; versions are recorded in the parent requirements files.

Its [dependency pin](https://github.com/ygelfand/echolocal/blob/6eff3b12db168223df3871f0a56250e736d3954a/go.mod), [backend](https://github.com/ygelfand/echolocal/blob/6eff3b12db168223df3871f0a56250e736d3954a/internal/feature/detect/backends.go), and [event engine](https://github.com/ygelfand/echolocal/blob/6eff3b12db168223df3871f0a56250e736d3954a/internal/feature/detect/engine.go) define this workflow's behavior.

`reference-sources.json` records URLs, byte sizes and SHA-256 values for optional upstream model/audio fixtures. Downloading or publishing those files has separate provenance and licensing considerations; a dependency's code license should not be treated as blanket permission for every dataset or trained weight. They are not redistributed here.

Do not change the runtime pin to make a failed export pass without also treating the target device runtime as a different compatibility target and repeating validation. Rebuilding a frozen validator changes its identity and requires a new evaluation protocol.
